## 自動検証

15件成功。数値計算7件、実UIモジュールを使用したDOMイベント5件、インストーラー3件。

- 符号・小数・全角を解釈し、空欄・途中の符号・非数値は拒否する。
- 公式関数で3方向の大きさ・足元を連動させ、画像パスを保持する。
- 左右・濃さは表示中の方向だけに反映する。濃さ0/100%を正しく保存する。
- 0.1cmの反復操作とShiftの10倍操作に見える丸め誤差を残さない。
- 範囲外・ロック・読み込み中・画像なしではデータを更新しない。
- 透過余白が異なる3画像にも、公式の高さ・座標制約を適用する。
- 未知の版／接続点の不一致／二重パッチを拒否する。
- 導入→検査→再導入→復元→再導入で、公式入口とプロジェクト相当のダミーファイルを保持する。
- A版導入後、B版の復元操作→B版導入が成功する。
- 不明な手動変更があるときは、他のファイルへ書く前に停止する。
- 別欄の確定で不正入力を消さず、プレビュー操作前に有効入力を確定する。
- 丸めた最小値を再確定しても元の精度を保持する。
- 大きさを変更して有効になった未確定の足元入力を、方向切替前に確定する。
- 同じ入力確定に伴う画面更新が、固定チェックONの意図を取り消さない。

## 実画面で確認した操作

| 入力・操作 | 結果 |
|---|---|
| 足元−0.7cm → ↑ → Shift+↑ | −0.6cm → 0.4cm |
| 左右を空欄にしてEnter | エラーと適用無効、勝手に0へ変更しない |
| 左右に「−」、続けて濃さ50をEnter | 「−」と不正状態を保持し、適用を無効のままにする |
| 入力途中にEscape | その欄の確定値へ戻る |
| 左右10を入力後、プレビュー操作→ドラッグ | 10を先に確定し、ドラッグ後の数値が表示される |
| 最小大きさを入力し、丸めた表示のまま再度Enter | 保存している精度を保持し、誤って範囲外にしない |
| 濃さ50%、方向切替 | 他方向の濃さを保持、大きさと足元は共通 |
| 位置・大きさの固定 | 対象入力を無効化し、濃さは変更可能 |
| 中央に戻す | 左右が0cmになる |
| キャンセル→再度開く | テスト前の調整値が保持される |

実プロジェクトの操作テストはキャンセルで終了し、テスト前後の保存ファイルSHA256一致を確認済み。画像、採用モデル、モデル座標をテストのために保存変更していない。
